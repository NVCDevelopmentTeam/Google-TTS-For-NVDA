Google TTS для NVDA

Додаток для NVDA, що використовує синтез мовлення WebAssembly (WASM) із Google Chrome для отримання якісних природних голосів в офлайн-режимі.

Цей додаток розроблено спільно з Nguyen Anh Duc та Dao Duc Trung.

Поточний стан

Наразі цей додаток активно підтримується та розвивається Нгуєн Ан Дуком та Дао Дук Трунгом. Хоча додаток і працює, у ньому все ще є кілька відомих проблем, над вирішенням яких ми працюємо:

  • Під час першої ініціалізації голоси можуть завантажуватися повільно.
  • Паузи та сегментація мовлення іноді можуть бути неправильними.

Ми дуже раді будь-яким відгукам від спільноти, які допоможуть нам стати кращими, і щиро їх цінуємо!

Остання стабільна версія

Google TTS для NVDA 0.5, останнє оновлення — 22 липня 2026 року.

  • Повний список змін для версії 0.5: Примітки до випуску Google TTS для NVDA v0.5
  • Завантажити останній стабільний пакет додатка: googleTtsForNvda-0.5.nvda-addon

Особливості

  • Комплексна підтримка голосового керування: Підтримує всі мови та голоси, доступні у WasmTtsEngine. Це включає пакети Chrome OS (оптимізовані для частого використання та високошвидкісного читання) та пакети Google Natural (розроблені для вищої якості, стандартного читання тексту).
  • 100% офлайн-мовлення: мовлення генерується локально за допомогою підтримуваного середовища виконання браузера Chromium, такого як Google Chrome, Microsoft Edge або Brave.
  • Низька затримка: Використовує вдосконалену сегментацію тексту (менше перше речення) для забезпечення миттєвих голосових відповідей.
  • Тимчасовий аудіокеш: кеш у пам’яті для коротких фраз (до 200 символів), що дозволяє безпечно оптимізувати повторювані фрази.
  • Автоматичні мовні профілі: за бажанням можна використовувати профілі для окремих мов, щоб для різних мов можна було задавати власні параметри голосу та мовлення.
  • Графічний інтерфейс менеджера голосів: Перевірка, завантаження або видалення голосів пакетами за допомогою інтерфейсу з множинним вибором за допомогою прапорців.
  • Фонові операції: Неблокуюче завантаження та видалення у фонових потоках.
  • Вибір середовища виконання браузера Chromium: оберіть Google Chrome, Microsoft Edge або Brave як фонове середовище виконання браузера.
  • Швидкий доступ: Натисніть NVDA+Ctrl+Shift+G, щоб миттєво відкрити «Менеджер голосів».
  • Вбудоване оновлення додатка: перевірка оновлень додатка у налаштуваннях NVDA з можливістю автоматичної перевірки один раз після кожного запуску.

Вимоги

  • NVDA: версія 2024.1 або новіша. Додаток підтримує NVDA версій 2024–2026 як для 32-бітних (x86), так і для 64-бітних (x64) збірок NVDA.
  • Середовище виконання браузера Chromium: у системі має бути встановлено Google Chrome, Microsoft Edge або Brave. Середовище виконання Microsoft Edge WebView2 потрібне лише тоді, коли Microsoft Edge вибрано або використовується як основне середовище виконання; Google Chrome та Brave не використовують WebView2.
  • Інтерактивний сеанс користувача Windows: робота додатка залежить від фонового середовища виконання браузера Chromium. Не слід покладатися на нього в середовищах, де це середовище недоступне або його запуск заборонено, наприклад, на екрані входу в систему Windows, у контекстах безпечного робочого столу, середовищі Windows PE, середовищах відновлення чи інших мінімальних сеансах Windows.

Встановлення та перший запуск

  1. Завантажте найновіший пакет .nvda-addon зі сторінки Випусків.
  2. Відкрийте пакет (або скористайтеся меню NVDA «Магазин додатків» -> «Встановити з зовнішнього джерела») і дотримуйтесь вказівок для його встановлення.
  3. Під час першого вибору Google TTS для NVDA як синтезатора, якщо голоси не встановлено, NVDA повідомить вас про це та автоматично відкриє діалог «Менеджер голосів Google TTS...», щоб ви могли завантажити принаймні один голос для використання.
  4. Крім того, ви також можете натиснути NVDA+Ctrl+Shift+G або перейти до Меню NVDA -> Інструменти -> Менеджер голосів Google TTS... у будь-який час, щоб керувати своїми пакетами.
  5. Позначте прапорці біля потрібних голосів і натисніть Завантажити вибрані голоси.

Керування мовними пакетами

Менеджер голосів Google TTS має дві вкладки:

  • Встановлені: показує мовні пакети, що вже збережені на вашому комп’ютері. Стовпець Стан повідомляє, чи є пакет придатним для використання, чи не підтримується вбудованим синтезатором, чи відсутній необхідний компонент, чи є пакет обов’язковим для іншого встановленого пакета або залежним від іншого пакета.
  • Завантаження: показує пакети, доступні для завантаження. Стовпець Стан пояснює, чи доступний пакет, чи потребує він іншого пакета, чи має вже встановлений необхідний компонент, або чи є він необхідним для інших пакетів, доступних для завантаження.

На кожній вкладці елементи керування розташовані в такому порядку: Фільтр за мовою, Вибрати всі мовні пакети, список пакетів, а потім Видалити вибрані мовні пакети або Завантажити вибрані мовні пакети. Діалог також містить рядок Стан і кнопки Оновити, Відкрити папку мовних пакетів і Закрити.

Щоб додати голоси, перейдіть на вкладку Завантаження, позначте потрібні пакети та натисніть Завантажити вибрані мовні пакети. Щоб видалити голоси, перейдіть на вкладку Встановлені, позначте пакети, які вам більше не потрібні, і натисніть Видалити вибрані мовні пакети.

Деякі мовні пакети залежать від інших. Під час завантаження залежного пакета Менеджер голосів може також завантажити необхідний компонент. Під час видалення пакета, від якого залежать інші встановлені пакети, Менеджер голосів додатково видаляє ці залежні пакети, щоб ви не залишили в системі непридатні до використання голоси.

Менеджер голосів захищає вас від випадкового видалення останнього доступного мовного пакета. Якщо «Google TTS для NVDA» не є поточним синтезатором, початкове попередження має значення Ні. Якщо «Google TTS для NVDA» є поточним синтезатором, Менеджер голосів запропонує спочатку перемкнутися на інший синтезатор і залишить останній придатний пакет встановленим, якщо ви не зміните налаштування.

Завантаження та видалення виконуються у фоновому режимі. Сповіщення про перебіг виконання обмежуються лише основними етапами та остаточними результатами, щоб не повторювати інформацію про кожну незначну зміну відсотків.

Налаштування конфігурації

Налаштування синтезатора

У діалозі налаштувань «Мовлення» NVDA доступні параметри Паузи для Google TTS незалежно від того, увімкнені автоматичні мовні профілі чи вимкнені. Коли автоматичні мовні профілі вимкнені, у діалозі також доступні такі параметри:

  • Голос: Виберіть мову Google TTS із встановлених.
  • Варіант: Виберіть назву голосу для цієї мови, включаючи голоси Chrome OS та Google Natural, якщо вони встановлені.
  • Швидкість: Швидкість мовлення. Пакети, що не належать до SeaNet, використовують швидкість, задану в середовищі виконання браузера Chromium; пакети SeaNet можуть використовувати штучну обробку швидкості після синтезу на вищих швидкостях.
  • Додаткове прискорення: Увімкніть, щоб подвоїти обчислену швидкість мовлення для швидкого читання. Швидкісне мовлення SeaNet може споживати більше ресурсів процесора, оскільки додаток обробляє згенерований аудіосигнал після синтезу.
  • Висота: Регулювання висоти мовлення.
  • Гучність: Гучність мовлення (відповідає діапазону гучності 0,0–1,0 у середовищі виконання браузера Chromium).

Паузи дозволяють вибрати, чи залишати паузи без змін, скорочувати їх лише в кінці тексту чи скорочувати протягом усього мовлення для швидшого читання. Це налаштування застосовується до всіх голосів Google TTS.

Налаштування Google TTS для NVDA

Додаток містить спеціальну панель налаштувань у розділі Налаштування NVDA (Меню NVDA -> Параметри -> Налаштування) -> Google TTS для NVDA: * Середовище виконання браузера Chromium: виберіть, яке з підтримуваних середовищ виконання браузера Chromium використовувати (Google Chrome, Microsoft Edge або Brave). На панелі показується інформація про доступність браузерів у вашій системі. * Стан середовища виконання браузера Chromium: Перегляньте вибране середовище виконання, доступність браузерів та активне резервне середовище виконання, якщо таке використовується. * Використовувати автоматичні мовні профілі: Увімкніть автоматичний вибір профілю та відкрийте елементи керування профілями, описані нижче. * Бажана мова профілю: Оберіть мову увімкненого профілю, яка використовуватиметься, коли речення є нечітким. Цей список може бути порожнім, доки не буде увімкнено хоча б один мовний профіль. * Автоматичний мовний профіль: виберіть, який із встановлених мовних профілів потрібно редагувати. * Використовувати цей мовний профіль: увімкніть вибраний мовний профіль. * Варіант, Швидкість, Додаткове прискорення, Висота, Гучність, Відсоток зміни висоти при великій літері, Промовляти «велика літера» перед великими літерами, Звуковий сигнал для великих літер, Використовувати функцію посимвольного читання, якщо підтримується: налаштуйте параметри мовлення для вибраного увімкненого профілю. * Стан автоматичних мовних профілів: Перевірте, чи профілі вимкнені, недоступні, чи відсутній вибраний профіль, або чи вони активні. * Оновлення: Містить елементи керування оновленнями додатка, наведені нижче. * Автоматично перевіряти наявність оновлень додатка під час запуску NVDA: Дозвольте Google TTS для NVDA перевірити наявність оновлень один раз після наступного запуску NVDA. Початково ця опція вимкнена. * Стан оновлення додатка: Перегляньте версію встановленого додатка, чи увімкнено або вимкнено автоматичну перевірку під час запуску, а також чи виконується перевірка зараз. * Перевірити наявність оновлень...: Вручну перевірити наявність останньої стабільної версії додатка.

Власні шляхи до середовища виконання браузера

Google TTS для NVDA зазвичай автоматично визначає Google Chrome, Microsoft Edge або Brave за типовими місцями встановлення в Windows та за даними реєстру. Якщо ви використовуєте портативний браузер, власну папку встановлення або керований комп’ютер, на якому браузер встановлено в нестандартному місці, вкажіть повний шлях до виконуваного файлу браузера в одній із таких змінних оточення:

  • CHROME_PATH для Google Chrome
  • EDGE_PATH для Microsoft Edge
  • BRAVE_PATH для Brave

Цей параметр повинен вказувати на файл .exe браузера, а не лише на папку, в якій він знаходиться. Типові приклади:

text C:\Program Files\Google\Chrome\Application\chrome.exe C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe C:\Program Files\BraveSoftware\Brave-Browser\Application\brave.exe

Щоб встановити шлях за допомогою графічного інтерфейсу Windows:

  1. Натисніть Windows+R, щоб відкрити діалог «Виконати».
  2. Введіть SystemPropertiesAdvanced і натисніть Enter. Відкриється вкладка «Додатково» діалогу «Властивості системи».
  3. Натискайте клавішу Tab, доки не дійдете до пункту «Змінні оточення...», а потім натисніть Enter.
  4. У розділі Користувацькі змінні виберіть Створити.... Використовуйте Користувацькі змінні, якщо вам не потрібно застосовувати це налаштування для всіх облікових записів Windows на комп’ютері; для редагування Системних змінних можуть знадобитися права адміністратора.
  5. У полі Ім’я змінної введіть одне з таких імен: CHROME_PATH, EDGE_PATH або BRAVE_PATH.
  6. У полі Значення змінної введіть повний шлях до відповідного виконуваного файлу браузера, наприклад C:\Program Files\Google\Chrome\Application\chrome.exe.
  7. Натисніть Гаразд, щоб закрити кожний діалог.
  8. Перезапустіть NVDA, щоб додаток міг зчитати нове значення.

Примітка для програми зчитування з екрана: у діалозі Змінні оточення є два списки змінних: спочатку Користувацькі змінні, а потім Системні змінні. Якщо ви чуєте список системних змінних, натисніть Shift+Tab, щоб повернутися до елементів керування користувацьких змінних, або продовжуйте натискати Tab, доки не дійдете до кнопки Створити..., що стосується користувацьких змінних.

Щоб налаштувати шлях (path) для поточного користувача Windows через командний рядок або PowerShell, скористайтеся командою setx:

bat setx CHROME_PATH "C:\Path\To\chrome.exe" setx EDGE_PATH "C:\Path\To\msedge.exe" setx BRAVE_PATH "C:\Path\To\brave.exe"

Після встановлення або зміни однієї з цих змінних перезапустіть NVDA, щоб додаток міг зчитати нове значення. Потім відкрийте Налаштування NVDA -> Google TTS для NVDA і виберіть відповідне середовище виконання браузера Chromium.

Вам потрібно встановити змінну лише для того середовища виконання, яке ви хочете замінити. Якщо змінна відсутня або вказує на файл, якого не існує, додаток продовжує перевіряти стандартні місця встановлення.

Оновлення додатка

Відкрийте Налаштування NVDA -> Google TTS для NVDA і натисніть Перевірити наявність оновлень..., щоб перевірити наявність останньої стабільної версії. Під час ручної перевірки з’являється діалог «Гаразд», якщо додаток вже оновлено, якщо немає підключення до Інтернету або якщо відповідь щодо оновлення неможливо розпізнати.

Якщо доступна новіша версія, Google TTS для NVDA показує діалог Інформація про оновлення із розміром завантаження, мінімальною версією NVDA, останньою протестованою версією NVDA та журналом змін. Виберіть Так, щоб завантажити пакет .nvda-addon у NVDA. Під час завантаження у діалозі Завантаження оновлення Google TTS для NVDA показується Статус завантаження, індикатор виконання (якщо розмір відомий) та кнопка Скасувати. Додаток перевіряє завантажений файл на відповідність розміру та контрольній сумі SHA256, вказаним у маніфесті оновлення, а потім відкриває стандартний інсталятор додатків NVDA.

Автоматичні перевірки під час запуску початково вимкнені. Якщо ви їх увімкнете, Google TTS для NVDA виконає перевірку один раз після наступного запуску NVDA і не видаватиме повідомлень, доки не з’явиться новіша версія. Ручна перевірка залишається доступною незалежно від того, увімкнено автоматичну перевірку чи ні. Якщо під час відкриття категорії налаштувань вже виконується фонова перевірка під час запуску, кнопка ручної перевірки буде неактивною до завершення цієї перевірки. Зміна стану прапорця «Автоматично перевіряти наявність оновлень додатка під час запуску NVDA» впливає на майбутні запуски NVDA і не перериває перевірку, яка вже виконується.

Для термінових виправлень розробники можуть опублікувати невелике оновлення, яке зберігає той самий публічний номер версії. Наприклад, оновлення може й надалі показуватись як Google TTS для NVDA 0.5 і мати ту саму назву файлу googleTtsForNvda-0.5.nvda-addon, але NVDA все одно може пропонувати його як нове оновлення додатка. Це дозволяє користувачам швидше отримувати важливі виправлення, пов’язані з сумісністю чи надійністю, не чекаючи на наступну публічну версію.

Автоматичні мовні профілі

Коли ви вмикаєте функцію Використовувати автоматичні мовні профілі, додаток використовує власні профілі для кожної мови замість стандартних налаштувань мовлення NVDA для виявлених речень. Якщо ввімкнено лише один мовний профіль, він застосовується до кожного речення. Це дозволяє зберегти ваші звичайні налаштування мови та варіантів Google TTS без змін на випадок, коли автоматичні мовні профілі вимкнені.

Автоматичні мовні профілі використовують вбудовані бібліотеки детекторів CLD2 як для 32-бітних (x86), так і для 64-бітних (x64) збірок NVDA. Результати CLD2 приймаються лише тоді, коли вони є достатньо надійними для однієї з увімкнених мов. Якщо текст занадто короткий або нечіткий, додаток використовує консервативні сигнали локальної мови, якщо такі є, а потім переходить до обраної увімкненої мови.

У категорії налаштувань «Google TTS для NVDA»:

  1. Увімкніть Використовувати автоматичні мовні профілі.
  2. Перейдіть до Бажана мова профілю. У цьому списку показується лише увімкнені мови, тому він може бути порожнім, доки ви не увімкнете профіль.
  3. Оберіть Автоматичний мовний профіль.
  4. Встановіть прапорець Використовувати цей мовний профіль для кожної мови, для якої ви хочете використовувати автоматичні мовні профілі. Мовні профілі залишаються вимкненими, доки цей прапорець не буде встановлено.
  5. Для кожної увімкненої мови налаштуйте Варіант, Швидкість, Додаткове прискорення, Висоту, Гучність, Відсоток зміни висоти для великих літер, Промовляти «велика» перед великими літерами, Звуковий сигнал для великих літер та Використовувати функцію посимвольного читання, якщо підтримується.
  6. Поверніться до розділу «Бажана мова профілю» і виберіть увімкнену мову, яка використовуватиметься, коли речення є нечітким або не містить достатньо мовних підказок.

У списку бажаних мов показується лише увімкнені мови. Для налаштування швидкості, висоти та гучності використовуються повзунки, подібні до параметрів мовлення в NVDA. Для регулювання висоти звуку великих літер використовується цифровий елемент керування зі стрілками, що дозволяє налаштувати її з високою точністю.

Категорія налаштувань Google TTS містить рядок стану, що стосується автоматичних мовних профілів. Його зміст змінюється залежно від поточного стану:

  • Якщо жоден мовний голосовий пакет не встановлено, з’являється запит встановити принаймні один мовний голосовий пакет.
  • Якщо автоматичні мовні профілі вимкнені, з’являється пояснення, що Google TTS використовує стандартні значення налаштувань мовлення NVDA для голосу, варіанту, швидкості, висоти тону, гучності, великих літер та посимвольного читання.
  • Якщо автоматичні мовні профілі увімкнені, але жоден мовний профіль не вибрано, з’являється запит вибрати принаймні один мовний профіль.
  • Якщо вибрано один або кілька профілів, з’являється пояснення, що використовуються вибрані встановлені мовні профілі; якщо вибрано один профіль, він використовується для кожного речення.

Загальні для NVDA налаштування, такі як рівень пунктуації та символів, автоматичне перемикання діалектів, повідомлення про зміну мови, нормалізація Unicode, дані Консорціуму Unicode, включаючи емодзі, додаткові словники символів, відкладений опис символів та вибір режимів мовлення, залишаються в налаштуваннях «Мовлення» NVDA.

Google TTS ігнорує власні команди NVDA щодо автоматичного перемикання мови та діалекту для цього синтезатора, тому ці глобальні налаштування не змушують Google TTS змінювати голоси. Використовуйте автоматичні мовні профілі Google TTS, якщо ви хочете, щоб у цьому додатку відбувався автоматичний вибір голосу/профілю. Якщо у NVDA увімкнено функцію «Повідомляти про зміни мови під час читання», назви мов, про які повідомляється, відповідають автоматичному виявленню мовних профілів Google TTS, коли профілі увімкнені. Коли профілі вимкнені, NVDA все одно може використовувати зміни мови, надані додатком, для повідомлення про мову та обробки символів, включаючи пунктуацію та словники символів, але Google TTS не змінюватиме голоси на основі цих команд.

Коли автоматичні мовні профілі вимкнені, голосові словники NVDA працюють у звичайному режимі для поточного обраного варіанту Google TTS. Коли автоматичні мовні профілі увімкнені, додаток тимчасово використовує голосовий словник для обраного варіанту кожного увімкненого мовного профілю під час обробки NVDA відповідного сегмента. Початкові словники NVDA та тимчасові словники й надалі працюють у звичайному режимі.

Коли автоматичні мовні профілі увімкнені, у налаштуваннях мовлення NVDA для цього синтезатора будуть недоступні стандартні параметри голосу, варіанту, швидкості, додаткового прискорення, висоти тону та гучності. Замість них показується сповіщення з можливістю фокусування, яке вказує на необхідність налаштування цих значень у розділі Налаштування NVDA -> Google TTS для NVDA. Параметр Паузи залишається доступним у налаштуваннях мовлення та застосовується до всього мовлення Google TTS. Команди кільця налаштувань синтезатора, такі як NVDA+Ctrl+Клавіші зі стрілками на desktop клавіатурах або NVDA+Shift+Ctrl+Клавіші зі стрілками на laptop клавіатурах, у цьому режимі замість зміни голосу чи параметрів мовлення Google TTS оголошують це сповіщення. Крім того, коли ввімкнено автоматичні мовні профілі, Google TTS використовує налаштування великих літер та посимвольного читання для кожного активного профілю; стандартні параметри мовлення знову стають доступними після вимкнення автоматичних мовних профілів. Статусні повідомлення в категорії налаштувань Google TTS для NVDA також доступні за допомогою клавіші Tab, щоб програми зчитування з екрана могли їх оголошувати.

Усунення несправностей, пов’язаних з відсутністю звуку в середовищі виконання Edge

Якщо ви обираєте Microsoft Edge як середовище виконання браузера на базі Chromium, Google TTS для NVDA також перевіряє, чи доступне середовище виконання Microsoft Edge WebView2. Може статися так, що Edge встановлено, але WebView2 відсутнє або пошкоджене, і в такому випадку додаток не зможе використовувати Edge для відтворення мовлення. Google Chrome та Brave не залежать від WebView2.

WebView2 — це середовище виконання Microsoft Edge, яке використовується нативними програмами Windows для відображення веб-вмісту. Воно пов’язане з Microsoft Edge, але наявність звичайного браузера Edge не завжди означає, що середовище виконання WebView2 встановлено та працює належним чином для потреб програм. Microsoft рекомендує для програм використовувати середовище виконання Evergreen WebView2, оскільки воно є спільним, автоматично оновлюється, а невелика програма Evergreen Bootstrapper завантажує середовище виконання, що відповідає архітектурі пристрою.

Коли потрібна WebView2, додаток Google TTS For NVDA пропонує кнопки для завантаження онлайн-програми Evergreen Bootstrapper від Microsoft, відкриття сторінки Microsoft WebView2 для офлайн-інсталяторів або пакетів із фіксованою версією, або відкласти зміну на пізніше. NVDA продовжує використовувати попередній синтезатор, доки WebView2 не стане доступною.

Якщо Windows не може відкрити сторінку завантаження, додаток показує адресу завантаження у полі з міткою «тільки для читання» та надає кнопку «Копіювати посилання», щоб ви могли вручну вставити адресу в браузер.

Для комп’ютера з доступом до Інтернету завантажте Evergreen Bootstrapper для Microsoft Edge WebView2 тут: Завантажити Microsoft Edge WebView2 Runtime.

Запустіть інсталятор, перезапустіть NVDA, а потім знову виберіть Google TTS For NVDA. Для офлайн-інсталяторів або пакета WebView2 Runtime із фіксованою версією відкрийте сторінку Microsoft WebView2: Microsoft Edge WebView2.
