Google TTS для NVDA

Авторы: Нгуен Ань Дык, Дао Дык Чунг и Фам Хунг Выонг

Долгое время пользователи скринридеров мечтали использовать знакомые голоса от технологии преобразования текста в речь Google на NVDA для Windows, подобно тому, как это реализовано на Android.

Google TTS для NVDA был создан, чтобы исполнить это желание. Используя технологию преобразования текста в речь Google через WebAssembly (WASM), работающую в поддерживаемом фоновом среде выполнения Chromium, таком как Google Chrome, Microsoft Edge или Brave, это дополнение привносит знакомые и естественные голоса Google, улучшая вашу повседневную работу за компьютером.

После загрузки нужных голосовых пакетов дополнение работает полностью автономно на вашем компьютере, обеспечивая отзывчивую речь без необходимости постоянного подключения к интернету.

Ключевые возможности

  • Полностью автономная работа: Синтез речи выполняется локально после загрузки необходимых голосовых пакетов.
  • Разнообразие языков и голосов: Предоставляет множество голосовых пакетов Google TTS для поддерживаемых языков.
  • Быстрый отклик и низкая задержка: Использует сегментацию текста и буферизацию аудио для повышения отзывчивости NVDA.
  • Менеджер голосов Google TTS: Позволяет просматривать, загружать, удалять и проверять голосовые пакеты из доступного диалогового окна.
  • Выбор среды выполнения Chromium: Возможность выбрать Google Chrome, Microsoft Edge или Brave в качестве поддерживаемой фоновой среды выполнения.
  • Автоматические языковые профили: Опционально использовать профили для каждого языка, чтобы разные языки имели свой собственный голос и параметры речи.
  • Встроенное обновление дополнения: Проверка обновлений дополнения из настроек NVDA с опциональной автоматической проверкой при каждом запуске.

Системные требования

  • NVDA: Версия 2024.1 или новее. Дополнение поддерживает NVDA с 2024 по 2026 год включительно, как для 32-разрядной (x86), так и для 64-разрядной (x64) сборок NVDA.
  • Браузер Chromium: Установленный Google Chrome, Microsoft Edge или Brave. Если вы используете Microsoft Edge в качестве среды выполнения, также должна быть доступна среда выполнения Microsoft Edge WebView2.
  • Интерактивный сеанс пользователя Windows: Не полагайтесь на это дополнение в средах, где среда выполнения Chromium не может быть запущена, например, на экране входа в Windows, в защищенных рабочих столах, в среде предустановки Windows (Windows PE), средах восстановления или других минимальных сеансах Windows.

Краткое руководство по началу работы

  1. Откройте диалоговое окно Выбор синтезатора NVDA, нажав NVDA+Ctrl+S, и выберите Google TTS For NVDA.
  2. Если голосовые пакеты не установлены, NVDA отобразит сообщение о том, что голоса Google TTS For NVDA не установлены. Нажмите OK, чтобы открыть Менеджер голосов Google TTS и загрузить голосовой пакет. Нажмите Отмена, чтобы пока остаться на текущем синтезаторе.
  3. В Менеджере голосов Google TTS загрузите хотя бы один голосовой пакет на вкладке Загрузка.
  4. После загрузки откройте Настройки речи (NVDA+Ctrl+V), чтобы выбрать предпочитаемый язык и вариант.

Управление голосами

Вы можете открыть Менеджер голосов Google TTS в любое время, чтобы добавить или удалить голосовые пакеты:

  • Нажмите сочетание клавиш NVDA+Ctrl+Shift+G, или
  • Перейдите в Меню NVDA → Сервис → Менеджер голосов Google TTS...

Менеджер голосов Google TTS имеет две вкладки:

  • Установленные: Показывает голосовые пакеты, уже хранящиеся на вашем компьютере. Столбец Состояние указывает, является ли пакет Пригодным для использования, не поддерживается ли он встроенным движком, отсутствует ли требуемый пакет, требуется ли он другим установленным пакетом или зависит от другого пакета.
  • Загрузка: Показывает пакеты, которые можно загрузить. Столбец Состояние поясняет, доступен ли пакет для загрузки, требует ли он другой пакет, установлен ли уже требуемый для него пакет или требуется ли он другим загружаемым пакетам.

На каждой вкладке элементы управления расположены в следующем порядке: Фильтр по языку, Отметить все голосовые пакеты, список пакетов, затем либо Удалить отмеченные голосовые пакеты, либо Загрузить отмеченные голосовые пакеты. Диалоговое окно также содержит строку Состояния и кнопки Обновить, Открыть папку с голосовыми пакетами и Закрыть.

Чтобы добавить голоса, используйте вкладку Загрузка, отметьте нужные пакеты и нажмите Загрузить отмеченные голосовые пакеты. Чтобы удалить голоса, используйте вкладку Установленные, отметьте пакеты, которые вы больше не хотите использовать, и нажмите Удалить отмеченные голосовые пакеты.

Некоторые голосовые пакеты зависят от другого пакета. При загрузке зависимого пакета Менеджер голосов может также загрузить требуемый пакет. При удалении пакета, от которого зависят другие установленные пакеты, Менеджер голосов включает эти зависимые пакеты в список удаляемых, чтобы вы не оставляли непригодные для использования голоса.

Менеджер голосов защищает вас от случайного удаления последнего пригодного для использования голосового пакета. Если Google TTS For NVDA не является текущим синтезатором, предупреждение по умолчанию выбирает Нет. Если Google TTS For NVDA является текущим синтезатором, Менеджер голосов предлагает сначала переключиться на другой синтезатор и сохраняет последний пригодный для использования пакет, если вы не переключитесь.

Вы можете использовать раскрывающийся список Фильтр по языку на любой вкладке, чтобы отображать только голосовые пакеты для нужного языка (например, английского или вьетнамского) и быстрее находить голоса. Кроме того, вы можете нажать Открыть папку с голосовыми пакетами, если хотите проверить, где на вашем компьютере хранятся голосовые пакеты.

Загрузка и удаление голосов выполняются в фоновом режиме, поэтому вы можете продолжать использовать NVDA без перерыва. Объявления о ходе выполнения ограничены основными этапами и конечными результатами, чтобы не повторять каждое небольшое изменение процентов.

Конфигурация

Настройки речи

Диалоговое окно настроек речи NVDA (NVDA+Ctrl+V) предоставляет параметр Паузы для Google TTS For NVDA как при включенных, так и при выключенных автоматических языковых профилях. Когда автоматические языковые профили отключены, диалоговое окно также предоставляет:

  • Голос: Выбор установленного языка Google TTS.
  • Вариант: Выбор имени голоса в пределах этого языка, включая голоса Chrome OS и Google Natural (если установлены).
  • Скорость: Регулировка скорости чтения.
  • Ускорение скорости: Включение удвоения скорости речи для высокоскоростного чтения.
  • Высота: Регулировка высоты голоса.
  • Громкость: Регулировка громкости речи.

Паузы: Выбор, остаются ли паузы неизменными, укорачиваются только в конце текста или укорачиваются по всей речи для более быстрого чтения. Этот параметр применяется ко всей речи Google TTS.

Настройки дополнения

В разделе Меню NVDA → Параметры → Настройки → Google TTS For NVDA вы можете настроить:

  • Среда выполнения Chromium: Выбор Google Chrome, Microsoft Edge или Brave в качестве фоновой среды выполнения Chromium для дополнения. Панель настроек отображает доступность браузеров.
  • Состояние среды выполнения Chromium: Просмотр выбранной среды выполнения, доступности браузеров и активной резервной среды выполнения, если она используется.
  • Держать среду выполнения Google TTS готовой в фоне: Включение, чтобы позволить Google TTS подготовить среду выполнения браузера и текущий голосовой пакет, пока активен другой синтезатор, что ускоряет переключение обратно на Google TTS. Этот параметр по умолчанию выключен. После его включения и нажатия OK или Применить, он может использовать больше памяти и держать файлы среды выполнения открытыми до тех пор, пока вы не выключите его или не закроете NVDA.
  • Состояние фоновой среды выполнения браузера: Просмотр, отключен ли этот параметр, не требуется ли он, поскольку Google TTS уже является текущим синтезатором, или ожидает запуска после нажатия OK или Применить.
  • Использовать автоматические языковые профили: Включение автоматического выбора профиля и открытие элементов управления профилями, описанными ниже.
  • Предпочтительный язык профиля: Выбор включенного языка профиля, используемого, когда предложение неоднозначно. Этот список может быть пустым, пока не включен хотя бы один языковой профиль.
  • Автоматический языковой профиль: Выбор установленного языкового профиля для редактирования.
  • Использовать этот языковой профиль: Включение выбранного языкового профиля.
  • Вариант, Скорость, Ускорение скорости, Высота, Громкость, Изменение высоты для заглавных букв (в процентах), Сообщать "заглавная" перед заглавными, Сигнал для заглавных, Использовать функцию произнесения по буквам, если поддерживается: Настройка параметров речи для выбранного включенного профиля.
  • Состояние автоматических языковых профилей: Просмотр, отключены ли профили, недоступны, отсутствует выбранный профиль или активны.
  • Обновления: Содержит элементы управления обновлением дополнения, описанные ниже.
  • Автоматически проверять наличие обновлений дополнения при запуске NVDA: Разрешить Google TTS For NVDA проверить один раз после следующего запуска NVDA. По умолчанию выключено.
  • Состояние обновления дополнения: Просмотр установленной версии дополнения, включена ли автоматическая проверка при запуске и выполняется ли проверка в данный момент.
  • Проверить обновления...: Ручная проверка последней стабильной версии дополнения.

Категория настроек Google TTS For NVDA также может быть открыта с помощью пользовательского жеста ввода. По умолчанию для нее не назначено сочетание клавиш; назначьте его в разделе Меню NVDA → Параметры → Жесты ввода в категории Google TTS For NVDA.

Обновления дополнения

Откройте Меню NVDA → Параметры → Настройки → Google TTS For NVDA и нажмите Проверить обновления..., чтобы проверить последнюю стабильную версию. Ручная проверка отображает диалоговое окно с сообщением OK, когда дополнение уже обновлено, когда нет подключения к интернету или когда ответ об обновлении не может быть понят.

Когда доступна новая версия, Google TTS For NVDA показывает диалоговое окно Информация об обновлении с размером загрузки, минимальной версией NVDA, последней протестированной версией NVDA и журналом изменений. Выберите Да, чтобы загрузить .nvda-addon пакет внутри NVDA. Во время загрузки диалоговое окно Загрузка обновления Google TTS For NVDA показывает Состояние загрузки, индикатор выполнения, когда размер известен, и кнопку Отмена. Дополнение проверяет загруженный файл на соответствие размеру и контрольной сумме SHA256 из манифеста обновления, а затем открывает обычный установщик дополнений NVDA.

Автоматическая проверка при запуске по умолчанию выключена. Если вы включите ее, Google TTS For NVDA проверит один раз после следующего запуска NVDA и не будет ничего сообщать, если не доступна новая версия. Ручная проверка остается доступной независимо от того, включена автоматическая проверка или нет. Если фоновая проверка при запуске уже выполняется, когда открыта категория настроек, кнопка ручной проверки отключается до завершения этой проверки. Изменение флажка Автоматически проверять наличие обновлений дополнения при запуске NVDA влияет на будущие запуски NVDA и не прерывает уже выполняющуюся проверку.

Механизм обновления также может распознавать небольшие исправления внутри одной и той же публичной версии. Это позволяет разработчикам публиковать исправления совместимости или надежности без изменения отображаемого номера версии, в то время как NVDA все равно может предложить более новую сборку, если метаданные релиза указывают на ее наличие.

Автоматические языковые профили

Когда Использовать автоматические языковые профили включено, для обнаруженных предложений используются языковые профили дополнения вместо обычных настроек речи NVDA. Если включен только один языковой профиль, этот профиль используется для каждого предложения. Ваши обычные настройки языка и варианта Google TTS снова становятся доступными, когда автоматические языковые профили отключены.

Автоматические языковые профили используют встроенные библиотеки детектора CLD2 как для 32-разрядной (x86), так и для 64-разрядной (x64) сборок NVDA. Результаты CLD2 принимаются только тогда, когда они достаточно надежны для одного из включенных языков. Если текст слишком короткий или неоднозначный, дополнение использует консервативные локальные языковые сигналы, где это возможно, а затем возвращается к предпочтительному включенному языку.

  1. Откройте Меню NVDA → Параметры → Настройки → Google TTS For NVDA.
  2. Включите Использовать автоматические языковые профили.
  3. Перейдите к Предпочтительный язык профиля. В этом списке отображаются только включенные языки, поэтому он может быть пустым, пока вы не включите профиль.
  4. Выберите Автоматический языковой профиль.
  5. Установите флажок Использовать этот языковой профиль для каждого языка, который вы хотите использовать в автоматических языковых профилях. Языковые профили отключены, пока этот флажок не установлен.
  6. Для каждого включенного языка установите Вариант, Скорость, Ускорение скорости, Высота, Громкость, Изменение высоты для заглавных букв (в процентах), Сообщать "заглавная" перед заглавными, Сигнал для заглавных и Использовать функцию произнесения по буквам, если поддерживается.
  7. Вернитесь к Предпочтительный язык профиля и выберите включенный язык, используемый, когда предложение неоднозначно.

Элементы управления скоростью, высотой и громкостью используют ползунки, как в настройках речи NVDA. Изменение высоты для заглавных букв использует поле редактирования/вращения с цифрами, чтобы вы могли точно настроить его.

Общесистемные настройки NVDA, такие как уровень пунктуации и символов, автоматическое переключение диалектов, сообщение об изменении языка, нормализация Юникода, данные консорциума Юникода, включая эмодзи, дополнительные словари символов, задержка описания символов и выбор режима речи, остаются в настройках речи NVDA.

Google TTS игнорирует собственные команды автоматического переключения языка и диалекта NVDA для этого синтезатора, поэтому эти глобальные параметры не заставляют Google TTS менять голоса. Используйте автоматические языковые профили Google TTS, когда хотите автоматического выбора голоса/профиля в этом дополнении. Если опция NVDA Сообщать об изменениях языка при чтении включена, сообщаемые названия языков следуют определению автоматических языковых профилей Google TTS, пока профили включены. Когда профили отключены, NVDA все еще может использовать изменения языка, предоставляемые приложениями, для сообщения о языке и обработки символов, включая словари пунктуации и символов, но Google TTS не будет менять голоса по этим командам.

Автоматические языковые профили устанавливают языковой контекст до того, как NVDA обработает текст, поэтому произношение символов NVDA и обработка словарей речи остаются в обычном потоке речи для выбранного языкового контекста.

Когда автоматические языковые профили отключены, словари голосов NVDA работают нормально для выбранного в данный момент варианта Google TTS. Когда автоматические языковые профили включены, дополнение временно использует словарь голосов для выбранного варианта каждого включенного языкового профиля, пока NVDA обрабатывает этот сегмент. Словари NVDA по умолчанию и временные словари по-прежнему следуют обычному поведению NVDA.

Пока автоматические языковые профили включены, диалоговое окно настроек речи NVDA не будет предлагать обычные элементы управления голосом, вариантом, скоростью, ускорением скорости, высотой и громкостью для этого синтезатора. Вместо этого оно покажет доступное уведомление, направляющее вас в категорию настроек Google TTS For NVDA. Паузы остаются доступными в настройках речи и применяются ко всей речи Google TTS. Обычные команды кольца настроек синтезатора, такие как NVDA+Ctrl+клавиши со стрелками на настольной клавиатуре или NVDA+Shift+Ctrl+клавиши со стрелками на ноутбучной клавиатуре, объявляют это уведомление вместо изменения голоса Google TTS или параметров речи в этом режиме. Google TTS также использует параметры заглавных букв и произнесения по буквам каждого включенного профиля, пока автоматические языковые профили включены; обычные значения настроек речи снова становятся доступными, когда автоматические языковые профили отключены. Сообщения о состоянии в категории настроек Google TTS For NVDA также доступны с помощью клавиши Tab, чтобы скринридеры могли их озвучивать.

Устранение неполадок с беззвучной работой Edge

Если вы выбираете Microsoft Edge в качестве среды выполнения Chromium, Google TTS For NVDA также проверяет, доступна ли среда выполнения Microsoft Edge WebView2. Edge может быть установлен, а WebView2 отсутствовать или быть поврежден, и в этом случае дополнение не может использовать Edge для синтеза речи. Google Chrome и Brave не зависят от WebView2.

WebView2 — это среда выполнения Microsoft Edge, используемая родными приложениями Windows для размещения веб-контента. Она связана с Microsoft Edge, но наличие обычного браузера Edge не всегда означает, что среда выполнения WebView2 установлена и исправна для сценариев приложений. Microsoft рекомендует использовать Evergreen WebView2 Runtime для приложений, поскольку она является общей, автоматически обновляемой, а небольшой Evergreen Bootstrapper загружает соответствующую среду выполнения для архитектуры устройства.

Когда требуется WebView2, Google TTS For NVDA предлагает кнопки для загрузки онлайн-загрузчика Evergreen от Microsoft, открытия страницы WebView2 Microsoft для автономных установщиков или пакетов фиксированной версии, либо отложить изменение на потом. NVDA продолжает использовать предыдущий синтезатор, пока WebView2 не станет доступен.

Если Windows не может открыть страницу загрузки, дополнение показывает адрес загрузки в помеченном поле только для чтения и включает кнопку Копировать ссылку, чтобы вы могли вставить адрес в браузер вручную.

Для компьютера с доступом в интернет загрузите загрузчик Evergreen Microsoft Edge WebView2 здесь: Загрузить среду выполнения Microsoft Edge WebView2.

Запустите установщик, перезапустите NVDA, затем снова выберите Google TTS For NVDA. Для автономных установщиков или пакета среды выполнения WebView2 фиксированной версии откройте страницу WebView2 Microsoft: Microsoft Edge WebView2.

Примечания

  • Вам не нужно держать окно браузера Google Chrome, Microsoft Edge или Brave открытым во время использования NVDA. Дополнение автоматически подключается и обрабатывает речь в фоновом режиме.
  • Когда NVDA впервые начинает говорить после запуска, голосам может потребоваться короткое время для инициализации.
